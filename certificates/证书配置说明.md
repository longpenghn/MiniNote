# 证书配置说明

## 证书文件说明

本目录用于存放应用签名所需的证书文件。你需要将以下文件放置在此目录中：

### Debug 证书（开发调试用）
- `debug.p12` - Debug 密钥库文件
- `debug.cer` - Debug 证书文件
- `debug.p7b` - Debug 配置文件

### Release 证书（正式发布用）
- `release.p12` - Release 密钥库文件
- `release.cer` - Release 证书文件
- `release.p7b` - Release 配置文件

## 获取证书的步骤

### 1. 注册华为开发者账号
- 访问 [华为开发者联盟](https://developer.huawei.com/)
- 注册并完成实名认证

### 2. 创建应用
- 在开发者控制台创建应用
- 获取应用的 Bundle ID

### 3. 生成证书
- 在开发者控制台的"证书管理"中生成证书
- 下载 .p12 证书文件和 .p7b 配置文件

### 4. 配置密码
在 `build-profile.json5` 中更新以下信息：
- `storePassword`: 证书文件密码
- `keyPassword`: 密钥密码
- `keyAlias`: 密钥别名

## 安全提醒

⚠️ **重要**: 
- 不要将证书文件提交到版本控制系统
- 妥善保管证书密码
- Release 证书仅用于正式发布

## 文件结构
```
certificates/
├── debug.p12          # Debug 密钥库文件
├── debug.cer          # Debug 证书文件
├── debug.p7b          # Debug 配置文件
├── release.p12        # Release 密钥库文件
├── release.cer        # Release 证书文件
├── release.p7b        # Release 配置文件
├── .gitignore         # Git 忽略文件
└── 证书配置说明.md     # 本说明文件
```

## 构建命令

### Debug 构建
```bash
hvigorw assembleHap
```

### Release 构建
```bash
hvigorw assembleHap --mode release
```
